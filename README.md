# PortfolioHub

Bem-vindo ao meu repositório de projetos acadêmicos e pessoais.

## Objetivo
Este projeto foi desenvolvido com o objetivo de criar um portfólio acadêmico e profissional utilizando GitHub, Git e GitHub Pages.

## Estrutura do Repositório
- Projetos Acadêmicos
- Projetos Pessoais
- Documentação
- Slides

## Implantação do PortfolioHUB

### Planejamento
Foi elaborado um plano de implantação para organização dos projetos acadêmicos e pessoais.

### Integração com GitHub
O GitHub foi utilizado para armazenamento, versionamento e compartilhamento dos projetos.

### Gestão de Usuários e Segurança
Foram utilizadas boas práticas de segurança do GitHub, incluindo autenticação da conta e controle de acesso ao repositório.

### Compartilhamento e Controle de Versão
O Git foi utilizado para registrar alterações através de commits e manter o histórico das versões do projeto.

### Publicação
O projeto foi publicado utilizando GitHub Pages.

### Apoio da IA Gemini
O Google Gemini foi utilizado como ferramenta de apoio para consulta de boas práticas de implantação e documentação.

## Tecnologias Utilizadas
- HTML
- Git
- GitHub
- GitHub Pages
